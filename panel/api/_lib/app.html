    Ce rulează acum

    Ultimele rulări pe GitHub (fiecare durează 3–6 minute).

    Istoric postări

    Tot ce a postat programul, cu link direct pe Instagram.

    Cont & chei

    Cheile se salvează criptat în GitHub (Secrets). Nici panoul nu le mai poate citi după salvare.

    Gratuită: aistudio.google.com/apikey

    Deschide Graph API Explorer, alege aplicația ta, bifează instagram_basic instagram_content_publish pages_show_list pages_read_engagement pages_manage_posts pages_manage_engagement pages_read_user_content instagram_manage_comments business_management instagram_manage_insights instagram_manage_messages pages_messaging, apasă „Generate Access Token” și copiază-l aici. Panoul îl transformă într-unul care nu expiră.

    Ce funcționează (din rezultate)

    Vizualizări, salvări, distribuiri și like-uri pentru fiecare postare. Programul alege mai des temele, hook-urile și stilul care merg.

    Ce a învățat din contul tău

    Înainte de fiecare postare analizează reel-urile și caruselurile de pe @cont (texte, like-uri, comentarii, imagini) și se ghidează după ce merge. Se actualizează la ~3 zile.

    Răspunsuri la comentarii

    Ultimele comentarii la care a răspuns AI-ul (Instagram + Facebook).

    Setări

    Schimbă orele, temele și stilul. Se aplică de la următoarea postare.
